# CapituloIX - Frontend

Frontend del obligatorio 2 de Desarrollo Full Stack. Consume la API desarrollada en el obligatorio 1.

## Despliegue

- Frontend: https://capituloix.vercel.app
- Backend: https://obligatorio-desarrollo-full-stack-peach.vercel.app



## Uso de IA

Durante el desarrollo se utilizó IA como asistente para:

- Implementar las validaciones de los formularios con Formik y Yup, definir los estilos (CSS) y la adaptación a pantallas chicas. detectar y corregir errores, y explicar el funcionamiento del código visto en clase para poder entenderlo mejor
